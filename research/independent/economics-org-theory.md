# 中间层消亡：经济学与组织理论视角

> 调研日期：2026-03-18 | 独立调研，非基于用户提供材料
> 核心命题：软件是人机之间的中间层，管理层是意图与执行之间的中间层，AI 正在同时冲击所有中间层

---

## 一、AI 对软件产业经济学的冲击

### 1.1 SaaS 的"末日"（SaaSpocalypse）

a16z 在 2025 年初宣称 SaaS 黄金法则——"将人类任务流程化为软件并按席位收费"——**已不再成立**。软件 ETF 下跌 30%，Salesforce、Adobe 等公司股价数周内暴跌 25-30%。

**定价模式转变**：
- 从按席位到按结果：Decagon 按"每次对话处理"收费
- IDC 预测：到 2028 年，70% 的软件供应商将重构定价策略

### 1.2 毛利率的结构性变化

| 指标 | 传统 SaaS | AI-First SaaS (2026) |
|------|-----------|---------------------|
| 毛利率 | 78-85% | 55-70% |
| 每用户可变 COGS | 接近零 | 占收入 20-40% |

但反趋势同样显著：LLM 推理成本以每年约 10 倍的速度下降。

### 1.3 a16z 的"乐观反论"

AI 不会杀死软件，而是会**扩大软件产业**：
- **强化的护城河**：网络效应、品牌、专有数据
- **被削弱的护城河**：转换成本——AI 降低了切换摩擦
- **关键洞察**："困难的部分从来不是原始智能，而是知道用它做什么"
- **产业分化**："commodity 功能的薄包装"将消亡，深度集成反而更强

## 二、组织理论：中间管理层的消亡与重塑

### 2.1 关键数据

- **Gartner**：到 2026 年，20% 的组织将用 AI 削减超半数中层管理职位
- **Korn Ferry**：41% 的员工报告公司已减少管理层级
- **HBR/哈佛商学院**：追踪 50,032 名软件开发者，使用 GitHub Copilot 的开发者**项目管理工作下降 10%**，工作小组规模更小

### 2.2 企业实践案例

| 企业 | 组织变革 |
|------|---------|
| Amazon | 提高个人贡献者与管理者比例 |
| Moderna | HR 和技术部门合并为一个角色 |
| Klarna | AI 替代 700 名客服，年省 $1000 万，但后来部分回聘 |
| McKinsey | 部署数千个 AI agent 做幻灯片和研究摘要 |

### 2.3 现实约束

- **信任赤字**：64% 的企业领导者认为 Agent 部署最大障碍是组织信任
- **权力集中**：扁平化可能导致权力向顶层集中

## 三、Coase 交易成本理论的 AI 重解

### 3.1 "科斯奇点"（NBER）

当 AI agent 能自主搜索、谈判和交易时，交易成本趋近于零，市场与企业的边界将被根本重塑。

Coase 原始论点：企业存在因为市场交易成本高于内部管理成本。而交易成本的构成——了解价格、谈判条款、撰写合同、监督合规——正是 AI agent 能以极低边际成本执行的任务。

### 3.2 反面观点：摩擦迁移而非消失（California Management Review）

- **交易成本悖论**：微观层面任务自动化成本下降时，宏观层面组织凝聚力成本反而上升
- **数字"遗留代码"**：每位员工部署独立 agent 导致流程碎片化
- **新型守门人**：对外部 AI 平台依赖增加，形成新权力中心
- **核心警告**："AI agent 看似降低自动化成本，实际上增加了外部交易成本和组织凝聚力丧失"

## 四、"软件从资产变耗材" 的数据

### 4.1 开发成本数据

| 维度 | 数据 |
|------|------|
| CRUD 应用和内部工具 | 开发成本较十年前下降 **90%** |
| AI 辅助开发效率 | 节省 **30-60%** 编码、测试和文档时间 |
| AI 生成代码占比 | 2025 年 **41%** 代码由 AI 生成 |
| GitHub 2025 年 | 月均合并 4,320 万 PR（+23%），年提交近 10 亿（+25%） |
| LLM API 成本 | 自 2024 年以来每年下降约 **80%** |

### 4.2 限定条件

- AI-First SaaS 的 COGS 中可变成本占收入 20-40%
- AI 生成代码带来质量问题
- 维护成本可能被低估
- 但存在"耗材悖论"：如果每次修改都重新生成，维护成本也趋近于零

## 六、综合分析

### 6.1 两个中间层的平行消亡

| 维度 | 软件中间层 | 管理中间层 |
|------|-----------|-----------|
| 传统功能 | 将人类意图翻译为机器指令 | 将高层战略翻译为执行动作 |
| AI 的冲击 | Agent 直接理解意图并执行 | Agent 直接接收指令并报告 |
| 残存价值 | 领域知识、数据护城河、品牌信任 | 战略判断、组织文化、人际信任 |

### 6.2 四个关键悖论

1. **成本悖论**：AI 降低边际成本，但短期内增加总成本。长期推理成本以 10x/年下降
2. **摩擦悖论**：微观交易成本下降，宏观组织成本可能上升
3. **护城河悖论**：AI 削弱转换成本护城河，但强化网络效应和数据护城河
4. **耗材悖论**：生产成本趋近于零，但价值未归零——价值从代码转移到意图理解和领域知识

### 6.3 对 Agent-Native 设计的推论

1. **Skill 而非 App** — 分发单元从"应用程序"变成"能力"
2. **结果导向定价** — 按完成的任务收费，而非按席位
3. **可组合性 > 完整性** — 专用小型 agent/skill 优于全能型应用
4. **数据和领域知识是最终护城河** — 代码可瞬间生成，专有数据无法生成
5. **平台捕获最大价值** — Agent marketplace 具备赢家通吃动力学
