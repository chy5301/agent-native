## 经验教训

1. **整合优于发明**：外部已有高质量设计资源时，整合提炼比从零撰写效率更高，且结果更有说服力（三套来源互相验证）。
2. **产物形态要 dogfood**：设计指南本身应该是 Agent-Native 的（Skill 形态），这一决策让产物的说服力大幅提升。
3. **对标金标准控制体量**：Phase 2 产出 ~6,753 词的 reference，Phase 3 精简到 ~3,593 词。早期对标金标准可避免后期大幅删减。
4. **补充调研要及时整合**：计划制定后新增了 8 份补充调研，通过增量计划调整（而非推翻重来）有效吸收，计划拓扑不变。
5. **边界条件嵌入原则而非独立成章**：保持上下文紧密，读者不需要跳转就能理解"何时不适用"。
